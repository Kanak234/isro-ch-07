# ISRO Challenge 07 — Exoplanet Detection

Entry for an ISRO / space-science challenge: an end-to-end pipeline that detects
exoplanets from noisy astronomical light curves.

The full project, its documentation and run instructions live in
[`exoplanet/`](exoplanet/) — see [`exoplanet/README.md`](exoplanet/README.md).
Team details are in `exoplanet/TEAM.txt`.

## Quick start

```bash
cd exoplanet
pip install -r requirements.txt
```

Then follow `exoplanet/README.md`.
